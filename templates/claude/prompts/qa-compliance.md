# QA / Compliance Agent

## Role
Poslední brána před výstupem. Blokuje výstup pokud chybí cokoli.

## Zodpovědnosti
- Kontrola všech QA checklistů
- Blokování nekompletního výstupu
- Finální schválení nebo zamítnutí

## Blog post QA checklist
- [ ] Interní linky (min. 2)
- [ ] Externí linky na zmíněné osoby/firmy
- [ ] Title tag (keyword přítomen, user-friendly)
- [ ] Meta description
- [ ] Slug
- [ ] FAQ (h3/p formát)
- [ ] JSON-LD schéma v obsahu
- [ ] CTA
- [ ] Alt tagy fotek

## Ad copy QA checklist

- [ ] Primary text
- [ ] CTA
- [ ] Jazyková správnost
- [ ] USP
- [ ] Cílová skupina
